# 🔐 Random Password Generator

A simple, modern, and responsive Random Password Generator built with **HTML, CSS, and vanilla JavaScript**. Generate secure random passwords, customize their length and character types, and copy them to your clipboard with one click.

## ✨ Features

- **Custom Password Length:** Choose any length between 8 and 32 characters.
- **Character Options:** Include or exclude uppercase letters, lowercase letters, numbers, and special characters.
- **Secure Random Generation:** Uses the browser's built-in cryptographic random number generator.
- **One-Click Copy:** Copy your generated password to the clipboard.
- **Input Validation:** Ensures at least one character type is selected.
- **Responsive Design:** Works on desktop, tablet, and mobile devices.
- **Clean Interface:** Minimal design with a light background and a modern accent color.
- **No Dependencies:** Built using HTML, CSS, and JavaScript without frameworks, external APIs, or a backend.
- **Privacy-Friendly:** Passwords are generated locally in your browser.

## 🛠️ Technologies Used

- CSS3
- JavaScript (ES6+)

## 🚀 Getting Started

### Prerequisites

You only need a modern web browser, such as Chrome, Firefox, Edge, or Safari.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/random-password-generator.git
   ```

2. Navigate to the project directory:

   ```bash
   cd random-password-generator
   ```

3. Open `index.html` in your web browser.

Alternatively, download the repository as a ZIP file, extract it, and open `index.html`.

No package installation or build process is required.

## 🔒 Security and Privacy

- Password generation happens entirely in your browser.
- No passwords are transmitted to a server or stored by this application.
- The generator uses the Web Crypto API for secure random character selection.

**Note:** Always use unique passwords for different accounts. For highly sensitive accounts, consider using a reputable password manager.
